# 设计稿（项目级设计系统）

> 项目级文件，放在 `docs/设计稿.md`。
> 由 `flow-design-ui` **Full 模式**生成/更新；后续需求的 UI 设计在 **Lite 模式**下读取复用。
> 各需求的 `02-ui设计.md` 只写需求特有的页面/组件/状态与例外项，视觉 token 一律引用本稿。
>
> 首次生成：2026-10-12 · 来源需求：`docs/deliverables/x-gulu/`（阶段 1 极简 Chat 克隆）· 视觉方向由用户在三候选中拍板。

## 视觉主张

一台安静、清爽的工具：冷调灰白底、中性灰阶、唯一靛蓝强调——像 Linear / Vercel 文档的浅色质感，第一印象是"干净、专注、没有干扰"，让通用用户（含不写代码者）也能无压力上手。（2026-10-12 受众修订：原"给技术用户干活的工具"表述作废，目标用户改为通用用户，远期方向辅助办公。）

## 字体排印

- **字族与角色**：
  - 界面文字：`system-ui, -apple-system, "Segoe UI", sans-serif` —— 技术工具的中性务实选择
  - 代码与数据：`ui-monospace, "SF Mono", "JetBrains Mono", Menlo, monospace` —— 仅代码块、模型名、token 数
- **字阶**（均为 `letter-spacing: 0`，中文场景不加字距）：

| 角色 | 字号/字重/行高 | 用途 |
|------|----------------|------|
| title | 18px / 600 / 1.4 | 页面标题、引导标题 |
| heading | 16px / 600 / 1.5 | 模态标题、设置分节 |
| body | 14px / 400 / 1.7 | 正文、模型消息 |
| body-strong | 14px / 500 / 1.7 | 按钮、选中项 |
| meta | 13px / 400 / 1.5 | 侧栏条目、时间戳 |
| caption | 12px / 400 / 1.5 | 状态栏、toast、徽章 |
| mono | 13px / 400 / 1.6 | 代码块 |

- **行宽 / 行高**：消息正文行宽 ≤ 760px（约 72–78 字符）；衬线不用，正文行高 1.7 略大于默认，利于长回答阅读。

## 间距与圆角

- 间距标度（4 基数）：`space.xs=4` · `space.sm=8` · `space.md=12` · `space.lg=16` · `space.xl=24` · `space.2xl=32`
- 圆角标度：`radius.sm=6`（徽章）· `radius.md=8`（按钮、输入框、代码块）· `radius.lg=10`（用户消息）· `radius.xl=12`（模态）
- 阴影：常规元素不用阴影，仅模态框与下拉菜单用 `0 12px 40px rgba(26,26,30,.16)`

## 布局约束

- **内容列与输入框同轴同边**：可滚动的内容列（如消息列表）与下方固定输入框共用同一 ≤760px 居中列，左右边缘严格重合，滚动条不得使其偏移。
- **滚动条处理（唯一做法）**：滚动条宽度固定 `scrollbar-w = 8px`（`::-webkit-scrollbar { width }`），容器设 `scrollbar-gutter: stable`（内容长短都预留右侧沟槽，列不横跳），并把同一个 8px **镜像**到相邻非滚动容器（输入区、状态栏）的右侧内边距 —— 与 OS 滚动条是叠加式还是占位式无关，宽窗（列居中）与窄窗（列铺满）两种情形下都无偏移。
  - 勿用 `scrollbar-gutter: stable both-edges`：窄窗下列铺满宽度时，左侧沟槽会把内容推右 8px。
- 桌面侧栏 260px、顶栏 52px、内容列 ≤760px、设置表单 ≤720px；≤900px 侧栏转抽屉浮层。

## 动效

- 保留的用户触发动效：模态 120ms 淡入 + 2px 上移；下拉 100ms 淡入；抽屉 120ms 淡入 + 6px 上移（从触发按钮方向进入）；按钮 hover 100ms 色变。
- **全站唯一非用户触发动效：流式打字光标 ▌（0.9s 闪烁）——项目记忆点。**
- 无进场动画、无滚动淡入、无卡片 hover 抬升。
- `prefers-reduced-motion: reduce`：光标不闪（常显）、过渡时长归 0。

## 文案基调

- 用用户语言命名，全程同一动作同一词：按钮「发送」→ toast「已发送」；「删除会话」→「已删除会话」。
- 主动语态：「保存修改」而非「提交」。
- 错误 = 发生了什么 + 怎么修，不道歉不模糊：`请求失败：API key 无效（401）。请到设置检查服务商配置。`
- **去行话**：面向通用用户，界面文案不出现 base URL、provider、endpoint、token 等行话（高级设置折叠区内可保留必要字段名，并配一句说明）。
- 空态是行动邀请：`还没有会话，点上方「新会话」开始`；`还没有提供方` + 按钮「添加提供方」。
- 界面文案用简体中文；代码、模型名、API 字段保留英文。
